# Графік і батарея на GeekMagic

[English](DISPLAYS.md) · [До README](../README.uk.md)

> Доступно з **DTEK Monitor 2.0.0-rc6**. Оновіть інтеграцію й перезапустіть HA перед увімкненням сенсора дисплея.

Невеликий дисплей може показувати графік усіх груп на сьогодні, виділені групи вашого будинку та квартири, годинник, відлік до найближчої події й заряд батареї інвертора. Telegram-бот для цього не потрібен.

## Що потрібно

- GeekMagic із робочою передачею зображень у HA. Шаблони перевірені на **GeekMagic Display 1.6.0**, профілі SD_PRO та екрані 240×240; інші прошивки слід перевіряти на власному пристрої.
- Налаштований будинок або особистий рахунок у DTEK Monitor.
- Для батареї — сенсор заряду у відсотках і сенсор потужності **у ватах: плюс означає заряд, мінус — розряд**. Вони можуть належати будь-якій інтеграції. Якщо ваш датчик використовує інший знак або кВт, спочатку створіть відповідний шаблонний сенсор HA.
- Часовий пояс HA — Europe/Kyiv.

## Увімкніть дані для дисплея

1. Відкрийте **Налаштування → Пристрої та служби → DTEK Monitor**.
2. Виберіть пристрій будинку або потрібного особистого рахунку.
3. Серед вимкнених сутностей знайдіть **Дані графіка для дисплея**, відкрийте її налаштування та ввімкніть. Дочекайтеся появи стану й атрибутів.
4. Скопіюйте `entity_id`. Для квартири використовуйте сенсор саме рахунку: він врахує ваш вибір груп. Для всього будинку використовуйте сенсор будинку.

Сенсор вимкнений за замовчуванням. Його ввімкнення не додає запитів до ДТЕК: він використовує наявні перевірені дані. Велика таблиця в атрибуті `days` не записується в історію Recorder. У цьому сенсорі немає адреси, номера рахунку чи даних авторизації.

## Зберіть екран Hero

У панелі **GeekMagic** створіть новий екран із компонуванням **Hero** та темою **watchOS**. Додайте чотири віджети **HTML** у такому порядку:

| Місце | Шаблон | Entity (template data) |
|---|---|---|
| Велика верхня область | [grid.html](../examples/geekmagic/grid.html) | Ваш сенсор даних графіка |
| Знизу ліворуч | [groups.html](../examples/geekmagic/groups.html) | Той самий сенсор |
| Знизу посередині | [clock.html](../examples/geekmagic/clock.html) | Той самий сенсор |
| Знизу праворуч | [battery.html](../examples/geekmagic/battery.html) | Не потрібна |

Скопіюйте весь вміст відповідного файлу в **HTML Template**. У шаблоні батареї замініть `sensor.display_battery_percent` та `sensor.display_battery_power` на свої сутності. Перевірте попередній перегляд і призначте екран пристрою.

Для батареї ввімкніть **Animate** і встановіть **Animation Loop = 3.2**. У сутностях GeekMagic увімкніть **Animations**. Відсутність анімації не заважає показу значень. Рекомендований початковий інтервал оновлення екрана — **10 секунд**; він не змінює частоту опитування ДТЕК.

## Фактична наявність світла

Таблиця та відлік показують план ДТЕК. Для фактичного стану верхній віджет також може показувати зелене **«СВІТЛО Є»**, червоне **«СВІТЛА НЕМАЄ»** або сіре **«СТАН НЕВІДОМИЙ»**. Індикатор оновлюється разом із дисплеєм і залишається видимим, навіть коли графік недоступний.

Замініть `binary_sensor.display_grid_present` у `grid.html` на свій бінарний датчик **фактичної міської мережі** (`on` — є світло). Якщо дані відсутні або застаріли, цей датчик має ставати недоступним. Не використовуйте датчик графіка/живлення ДТЕК або резервований вихід інвертора. Для періодичного датчика частоти мережевого входу інвертора з резервним живленням є приклад [power.yaml](../examples/geekmagic/power.yaml): перевірка свіжості та затримки 10 с для зникнення / 30 с для відновлення. Спочатку замініть датчик, потім додайте приклад до наявних шаблонів HA. Бот для цього не потрібен.

Для генератора JSON передайте `--power-state binary_sensor.your_grid_present`; без цього параметра індикатор прихований. Якщо вставити HTML вручну без датчика, стан буде невідомим. Індикатор використовує власне джерело HA; бот може повідомити пізніше, очікуючи додаткового датчика підтвердження.

## Як читати екран

- **Блакитний фон** позначає групи будинку, **світла рамка** — вибрані особисті групи. Усі групи залишаються в таблиці.
- Помаранчева смуга — планове відключення; помаранчева штриховка — можливе; синюваті смуги — тижневий прогноз; сіра штриховка — відсутні дані. Темний проміжок без штриховки означає, що за підтвердженим графіком відключення там немає.
- Вертикальна лінія — поточний час. Минулі ділянки смуг зліва від неї приглушені; майбутні залишаються контрастними. Номери груп і рамки виділення не приглушуються. Межі смуг не округлюються до години; точність відображення обмежена пікселями екрана.
- Якщо груп понад 12, сторінки змінюються кожні 20 секунд. До шести груп будинку залишаються на кожній сторінці; за більшої кількості перегортається вся таблиця. Список власних груп також перегортається, якщо їх понад чотири.
- Відлік стосується найближчого початку або кінця відключення серед вибраних груп; при кількох групах зазначено, яких саме стосується подія. «Кінець за граф.» не підтверджує фактичне відновлення живлення.
- Якщо особисту групу не вибрано, показуються групи будинку й пропозиція вибрати свої в HA. Відлік для квартири не вгадується.
- **−148 Вт червоним** — розряд батареї, **+350 Вт зеленим** — заряд; **0 Вт** — нейтральний. Недоступний сенсор показує «—», а не нуль. Колір заповнення батареї залежить від заряду.

У разі помилки графіка старі смуги прибираються. Якщо сам HA, Wi-Fi або дисплей втратить зв'язок, пристрій може залишити останнє зображення: завмерлий годинник допомагає це помітити. Для роботи під час відключень потрібне резервне живлення HA, мережі й дисплея.

Шаблони можна редагувати через GeekMagic. [build_view.py](../examples/geekmagic/build_view.py) додатково формує JSON для користувачів API GeekMagic; він не встановлює екран і не звертається до HA чи ДТЕК.
